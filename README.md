# NovaDx — 다중 사이트 경영관리 시스템 (데모)

가상의 체외진단 기업 **노바진단(NovaDx)** 을 대상으로 만든 사내 경영관리 시스템입니다.
영업·회계·채권·해외법인까지 11개 업무 사이트를 하나의 로그인·권한 체계로 묶었습니다.

> 이 저장소의 모든 회사명·인명·거래처·금액은 **가공 데이터**입니다. 실재하는 조직·개인과 무관합니다.

**라이브** → https://mwpark0406.github.io/novadx/
로그인 계정은 요청 시 별도 안내드립니다.

| 해외 영업 | `intl.html` | 국가·딜러별 실적, 수주 파이프라인, 활동·일정, 견적, 파트별 현황 |
| 미국법인 | `us.html` | 매출·채권·수주·자금·영업예측 ERP |
| 인도법인 | `in.html` | 매출·채권·자금·비용·재고 ERP |
| 중국법인 | `cn.html` | 수주·입금·자금일보·CRM·자산 (한/중 이중언어) |
| 국내 미수금 | `receivables.html` | 채권 연령분석, 관리대상 분류, 대손 품의, 주간 추이, 임원보고 |

`index.html` 은 로그인 허브로 리다이렉트합니다.

## 기술 구성

- **프런트엔드**: 사이트당 단일 HTML 파일 (빌드 단계 없음). Chart.js, Bootstrap Icons.
- **백엔드**: Supabase — Auth(이메일·비밀번호), Postgres, Row Level Security
- **배포**: GitHub Pages
- **권한**: 계정마다 접근 가능한 사이트 키 목록(`access`)과 역할(`user`/`manager`/`admin`)을 부여.
  로그인 후 권한이 있는 사이트만 런처에 표시되고, 각 사이트 진입 시 서버 세션으로 다시 검증합니다.

## 만들면서 신경 쓴 것

**숫자 정합** — 같은 매출을 월별·거래처별·제품별·담당자별로 나눠 보여주는 화면이 여럿입니다.
어느 축으로 잘라도 합계가 회계 확정액과 일치하도록 데이터를 거래 단위로 만들고 위로 집계했습니다.
축마다 커버리지가 다를 때 생기는 잔차는 숨기지 않고 '미분류' 행으로 드러냅니다.

**기간 기준** — 진행 중인 달을 전년 같은 달(만근)과 비교하면 성장률이 왜곡됩니다.
성장률·모멘텀은 완결된 달까지만 잘라서 계산합니다.

**회귀 방지** — 한 번 고친 로직이 다음 작업에 밀려 조용히 되돌아가는 일이 반복됩니다.
화면은 멀쩡히 뜨고 숫자만 틀리기 때문에 눈으로는 안 잡힙니다.
그래서 남아 있어야 할 코드와 그 사유를 `.github/guards.json` 에 기록해두고 CI에서 검사합니다.

## 품질 검사

```bash
node .github/check-syntax.js   # 12개 HTML의 <script> 블록 파싱 검사
node .github/check-guards.js   # 고쳐둔 로직이 아직 남아 있는지 검사
```

push·PR 마다 GitHub Actions 가 자동으로 실행합니다 (`.github/workflows/checks.yml`).
